Raazdar Owner panel

Sign in

Paste the admin key. On the server, run cat /var/lib/raazdar/admin.key to see it.

Make voucher codes

Sell these codes (UPI, Razorpay link, bank transfer). The buyer types the code in Raazdar → You → Raazdar Plus. Codes are shown only once: save them right away.

Check or cancel a code

For support and refunds. Cancelling makes an unused code worthless.
