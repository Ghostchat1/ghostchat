What we could hand over, if legally required

Because of how Raazdar is built, this is the complete list of what exists on our server for an anonymous ID:

All of this lives in memory only and disappears when the server reboots.

How we handle requests

  1. We check that the request is valid under Indian law and issued by a competent authority.
  2. We push back on requests that are overly broad or lack a legal basis.
  3. We provide only what exists and is specifically required.
  4. Where the law allows, we tell the affected user (inside the app) and publish the request here.
