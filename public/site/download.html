iPhone & iPad

Install GhostChat to your Home Screen straight from Safari. It opens full-screen like any app.

  1. Open quietline.chat in Safari and tap Open GhostChat.
  2. Tap the Share button (square with an arrow).
  3. Choose Add to Home Screen, then Add.

Verify your Android download

Every official APK is signed with the same GhostChat key. Make sure your copy is genuine before you install it:

  1. Signing certificate (SHA-256):
    7D:9F:64:47:32:76:9B:E5:71:C2:A0:63:15:16:8A:84:4E:CA:64:34:CA:54:77:7B:28:63:CC:51:D1:13:60:CF
  2. Each release lists the file's SHA-256 checksum and includes a GhostChat.apk.sha256 file. See the latest release.
  3. On a computer: sha256sum GhostChat.apk and apksigner verify --print-certs GhostChat.apk must match the values above.

The source code is public at github.com/Ghostchat1/ghostchat. Releases are built automatically from that code by GitHub, not on anyone's laptop.
